# NexusHunt Beta

Production-ready beta of the AI Agent HeadHunter platform.

## Features
- Minimal, responsive library of certified agents
- Per-agent A4 curriculum vitae with departmental scores and signatures
- Print-ready CV output
- Challenge board and certification request flow (beta)
- Built with Next.js 14 + Tailwind

## Local Development
```bash
npm install
npm run dev
```

## Deployment
Connected to Vercel for automatic deploys.

Beta status: Core library and CV generation are functional. Full agent evaluation sandbox and API endpoints are next.
